# Contract: 기준 위치 선택 UI

## 목적

사용자가 장소 검색 없이 지도에서 기준 좌표를 명확히 선택하도록 로우파이, 하이파이 및 구현이
공유해야 하는 동작 계약이다.

## 필수 요소

| 요소 | 동작 |
|------|------|
| 지도 | 현재 선택된 기준 좌표를 중심으로 표시한다. |
| 기준 핀 | 지도 이동이 끝난 중심 좌표로 이동하며 선택 결과를 나타낸다. |
| 현재 위치 바로가기 | 위치 권한이 있으면 지도와 핀을 현재 위치로 이동한다. |
| 장소 이름 | 집·회사 또는 사용자가 직접 입력한 이름을 좌표와 함께 저장한다. |
| 반경 slider | 100m, 250m, 500m, 1km의 네 단계에 snap한다. |
| 저장 장소 재사용 | 기존 저장 장소를 다른 규칙의 기준 위치로 선택할 수 있게 한다. |
| 위치 확인 | 현재 핀 좌표를 기준 위치로 확정하고 이전 화면에 반영한다. |
| 권한 안내 | 현재 위치 바로가기에 필요한 권한이 없을 때 원인과 설정 방법을 안내한다. |

## 상태

- 초기 좌표 있음: 저장된 기준 위치를 지도와 핀에 표시한다.
- 초기 좌표 없음·현재 위치 사용 가능: 현재 위치를 초기 후보로 표시하되 사용자가 확인해야 한다.
- 초기 좌표 없음·위치 사용 불가: 기본 지도 범위를 표시하고 핀 이동으로 직접 선택할 수 있게 한다.
- 지도 이동 중: 핀 후보를 갱신하며 확인 동작은 마지막 안정된 중심 좌표를 사용한다.
- 위치 권한 없음: 핀 직접 지정은 유지하고 “현재 위치를 사용할 수 없으며 지도 핀 지정은 가능”함을
  안내한 뒤 현재 위치 바로가기만 시스템 설정 진입으로 전환한다.
- 직접 이름 입력: 393×852 viewport를 유지하고 keyboard 위로 입력 영역을 이동하거나 scroll한다.

## 범위 제외

- 장소명 또는 주소 검색과 자동 완성
- 주소 자동 완성
- 주소 문자열 또는 reverse geocoding 결과를 제한 판정 데이터로 저장

## 설계 승인 조건

- 로우파이에서 진입, 지도 이동, 현재 위치, 권한 없음, 확인·취소 흐름을 검토한다.
- 하이파이에서 지도 위 핀 가독성, 버튼 계층, Dynamic Type, VoiceOver label, 명암을 검토한다.
- 두 설계 산출물이 승인되기 전 SwiftUI 구현을 시작하지 않는다.
