## Description

집중이 필요한 순간, 앱을 참는 대신 환경을 바꿔 보세요.

나서는 시간과 장소를 함께 사용하는 집중 규칙으로 선택한 앱의 사용을 제한합니다. 집, 회사, 공부 장소처럼 자주 쓰는 위치와 반경을 정하고 요일과 시작·종료 시각을 선택하세요. 규칙이 활성화되면 선택한 앱이 제한되고, 시간이 끝나거나 설정한 반경 밖으로 이동하면 다시 사용할 수 있습니다.

주요 기능

- 시간과 위치 조건을 함께 사용하는 집중 규칙
- Screen Time에서 직접 선택하는 제한 대상 앱
- 집, 회사와 직접 입력한 장소를 저장해 다시 사용
- 100m, 250m, 500m, 1km 반경 설정
- 여러 규칙 생성과 요일별 반복 일정
- 활성 규칙과 제한 상태를 한눈에 확인
- 규칙과 장소 정보를 기기에 저장

자동 제한을 사용하려면 Screen Time 권한, 위치 접근 ‘항상 허용’, 정확한 위치가 필요합니다. 백그라운드 앱 새로 고침이 꺼져 있으면 상태 복원이 늦어질 수 있습니다.

나서와 함께 집중할 곳에서는 몰입하고, 때가 되면 가볍게 밖으로 나서세요.
